# Huntbound 项目方向

项目定位为 3D 四人合作狩猎游戏。核心期望是队员通过观察大型怪物的行动、选择攻击时机与相互支援完成任务。

## 已确定的要求

- 3D 游戏。
- 四位队友共同作战；当前项目按四人小队记录，最终人数表述可调整。
- 玩法体验可以参考《怪物猎人：世界》。
- 在本机建立游戏目录，并使用 GitHub 管理项目。

## 初始化采用的工作默认值

- 开发代号 Huntbound，随时可更名。
- 延续已有 Godot 4 开发环境；当前本机为 4.7.2 标准版。
- 仓库默认私有，先在个人 GitHub 账号下创建。
- 使用 GDScript，当前启动场景没有业务脚本。

## 实现前的设计讨论

首个可玩版本建议围绕一张小型竞技场、一种近战武器和一只具备少量清晰招式的大型怪物展开，再扩展为四人共同狩猎。

需要先确认的取舍包括：真人联机与 AI 队友的优先顺序、局域网与互联网联机范围、武器类型、镜头和锁定方式，以及动作节奏。

技术方案可比较本机房主加客户端、独立服务器和先做单人战斗再接入联机。建议先验证房主加客户端的四人会话，同时把最终伤害和怪物状态集中在房主端；这只是待讨论方案，当前工程未实现网络功能。
